## 🚀 Installation (5-10 Minutes)

### Step 1: Download the Theme

1. Go to: https://github.com/VELU1231/matthewuseee-shopify-scrap
2. Click the **"Code"** button (green)
3. Click **"Download ZIP"**
4. Save the file to your computer

### Step 2: Upload to Your Shopify Store

1. Log in to your **Shopify Admin Dashboard**
2. Go to **Online Store** → **Themes** (left sidebar)
3. Click **"Add theme"** button (top right)
4. Click **"Upload"**
5. Select the downloaded ZIP file
6. Wait for upload to complete (30-60 seconds)

### Step 3: Customize Your Theme

1. Find the newly uploaded theme in your themes list
2. Click **"Customize"** button
3. You'll now see the **Theme Editor** with all editable sections on the left panel

### Step 4: Publish Your Theme

1. When you're happy with your customizations, click **"Publish"** button (top right)
2. Your theme is now live on your Shopify store!

## 🎨 Editing Sections in Theme Editor

### Homepage Sections

Once you click "Customize," you'll see sections like:

#### **Hero Section** (First section on homepage)
- **Edit:** Click on the hero section
- **Change Background Image:** Click "Select image" → Upload your fragrance hero photo
- **Change Headline:** Edit the "Heading" text field
- **Change Buttons:** Edit button labels and URLs
- **Change Text Color:** Use the color picker

#### **Testimonials/Reviews** (Middle section)
- Click the section to edit
- Add review blocks by clicking **"Add block"**
- Edit reviewer name, review text, rating, and photo

#### **Product Grid** (Shows your scent collection)
- Select which collection to display
- Choose number of columns (2, 3, or 4)
- Customize button colors and labels

#### **FAQ Section** (Questions & Answers)
- Click to edit
- Add new Q&A blocks
- Edit question and answer text

### Adding New Sections

To add a section to your homepage:

1. Click the **"+"** icon between sections (or at the bottom)
2. Choose a section from the list
3. Fill in the settings
4. Click **"Save"**

### Removing Sections

1. Click the **"..."** menu on a section
2. Click **"Remove"**
3. Confirm deletion

### Reordering Sections

1. Click and drag any section up or down
2. The homepage updates instantly
3. Changes are automatically saved

## 🛍️ Adding & Managing Products

Products are managed **separately** from the theme in Shopify Admin.

### Add a New Product

1. Go to **Products** → **Add product**
2. Fill in:
   - Product name
   - Description
   - Price (in PHP)
   - Images (upload 3-5 high-quality photos)
   - Inventory quantity
3. Click **"Save product"**

### Add to Collection

1. Go to **Products** → **Collections**
2. Click the collection (e.g., "Scents", "Discovery Sets")
3. Click **"Add products"**
4. Search for your product and add it

### Set Out-of-Stock Notifications

Your theme includes **Restock Rocket** app integration:

1. Go to **Apps** → **Restock Rocket**
2. Enable "Notify me when back in stock" button
3. Customers can opt-in to notifications

## 🎨 Changing Colors & Fonts

### Change Primary Colors (Buttons, Links, Accents)

1. Click **"Customize"** on your theme
2. In the left panel, find **"Color Scheme 1"**
3. Edit:
   - **Primary Color** - Main button color (default: black #000000)
   - **Primary Hover** - Button hover state (default: gray #A6A6A6)
   - **Background** - Page background (default: white #FFFFFF)
   - **Text** - Body text color (default: dark gray #333333)
4. Changes apply instantly to entire store

### Change Fonts

1. Go to **Customize**
2. Look for **"Typography"** settings
3. You can override font families (advanced setting)

**Current fonts:**
- Headings: HelveticaNowDisplay (premium font)
- Body text: HelveticaNowDisplay Medium
- Buttons: HelveticaNowDisplay ExtraBold

## 🔧 Common Tasks

### Change Store Name
1. Go to **Settings** (bottom left in Shopify Admin)
2. Click **"Basic information"**
3. Edit **"Store name"** field
4. Click **"Save"**

### Change Store Logo
1. Go to **Customize** → **"Logo and favicon"** section
2. Click **"Select image"** 
3. Upload your logo
4. Save

### Add Announcement Bar
1. Go to **Customize**
2. Scroll to find **"Announcement bar"** section
3. Edit text (e.g., "FREE SHIPPING ON ORDERS OVER ₱1,200")
4. Changes appear at top of every page

### Change Footer Text
1. Go to **Customize**
2. Find **"Footer"** section
3. Edit address, phone, email, social links
4. Save

### Set Up Payments
1. Go to **Settings** → **Payment methods**
2. Enable payment options:
   - GCash
   - Maya
   - Credit/Debit Cards (Visa, Mastercard)
   - Bank Transfers
   - Cash on Delivery (COD)
3. Your theme displays payment icons automatically

## ❓ Frequently Asked Questions

### Q: Can I edit everything without coding?
**A:** Yes! The theme is fully editable in the Shopify Theme Editor. No coding required.

### Q: What if I break something?
**A:** Just click "Discard" before saving. Or restore from a previous version:
- Go to **Online Store** → **Themes**
- Find your theme
- Click **"..."** → **"View versions"**
- Restore a previous version

### Q: Can I add my own fonts?
**A:** Yes, but it requires uploading font files via:
- **Settings** → **Files** → Upload .ttf or .woff files
- Or contact a developer to integrate custom fonts

### Q: How do I add a new page (About Us, Contact)?
**A:** Go to **Pages** → **Add page** → Write content → Save
The page automatically appears in your navigation menu.

### Q: Can I change the homepage layout?
**A:** Yes! The homepage uses sections. You can:
- Add sections (click "+")
- Remove sections (click "..." → Delete)
- Reorder sections (drag & drop)
- Edit all section content

### Q: How do I set up email notifications?
**A:** Go to **Settings** → **Email** → Edit email templates.
Customers receive order confirmations, shipping updates automatically.

### Q: Can I offer variants (sizes, colors)?
**A:** Yes! When adding a product:
1. Go to **Products** → Select product
2. Scroll to **"Variants"** section
3. Click **"Add variants"**
4. Add size, color, quantity, different prices
5. Save

### Q: How do I track sales?
**A:** Go to **Analytics** → **Sales** in Shopify Admin
See daily/weekly/monthly sales, top products, customer data.

### Q: Can I add a discount code?
**A:** Yes!
1. Go to **Discounts** → **Create discount**
2. Choose discount type (percentage, fixed amount, free shipping)
3. Set code (e.g., "WELCOME10")
4. Set expiration date
5. Customers enter code at checkout

### Q: What's Restock Rocket?
**A:** An app that lets customers opt-in for "back in stock" notifications.
When a product becomes available again, they're notified via email.

## 🚨 Troubleshooting

### Theme won't load / shows "404"
1. Go to **Online Store** → **Themes**
2. Make sure your theme has a **"Publish"** button (not "Draft")
3. Click **"Publish"** if it's still in draft
4. Wait 30 seconds and refresh your store

### Sections look wrong / text is cut off
1. Go to **Customize**
2. Check **"Color Scheme"** settings
3. Verify no color overlaps are hiding text
4. Try a different browser (Chrome, Safari)

### Images aren't showing
1. Go to **Products** → Edit product
2. Make sure images are uploaded
3. Verify image file size < 5MB
4. Try uploading a different image format (.jpg preferred)

### Mobile looks broken
1. This is usually just DevTools preview
2. Test on an actual phone (iOS/Android)
3. Go to your store URL from phone browser
4. Everything should render correctly

### Can't find a section to edit
1. Go to **Customize**
2. Scroll through the left panel
3. Look for the section name
4. If missing, click **"+"** to add it
